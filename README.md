# Прокси-сервер HTTP с кешированием

Учебный проект по дисциплине «Технологии индустриального программирования»: консольный прокси-сервер HTTP на C++ с фильтрацией запросов по чёрному списку доменов, кешированием ответов и журналом обращений.

Сейчас в репозитории лежит документация проекта: спецификация требований (SRS) и UML-диаграммы. Реализация будет добавлена позже.

## Структура

| Путь | Содержимое |
|---|---|
| `SRS_HTTP_Proxy.md` | Спецификация требований (SRS), исходный текст |
| `docs/SRS_HTTP_Proxy.docx` | SRS в формате Word |
| `docs/SRS_HTTP_Proxy.pdf` | SRS в формате PDF с титульным листом |
| `diagrams/UseCase_HTTP_Proxy.drawio`, `.png` | Диаграмма вариантов использования |
| `diagrams/Sequence_HTTP_Proxy.drawio`, `.png` | Диаграмма последовательности |

## Диаграммы

Файлы `.drawio` открываются в [draw.io](https://www.drawio.com/) (настольная версия или app.diagrams.net). После правки диаграммы экспортируйте PNG с тем же именем в папку `diagrams/`: на эти картинки ссылается SRS.

## Документы

Файлы в `docs/` собраны из `SRS_HTTP_Proxy.md`. После изменений в SRS их нужно пересобрать, чтобы Word- и PDF-версии не отставали от исходного текста.
